My sprint goal is to make the inventory system modular and reusable because its better to work on modularity earlier on than to come back to your system and having to rewrite your entire system for modularity(technical debt). The reason why I chose these stories is because they make it clear on what the structure of the inventory system should look like. I also chose some of these stories because I know some people like developing mods for games so some compatibility is built into the system. I think all of these stories are acheiveable within a 1-4 week span since these can build upon some functions that the inventory system will use and also expand on developers wanting to add sound/visual effects or add buttons that do some sort of function.
